Gopayment.

Pembayaran QRIS di Vercel

Infrastruktur payment gateway yang jalan sepenuhnya di Vercel Serverless Functions. Buat tagihan, tampilkan QRIS dinamis, dan konfirmasi pembayaran secara otomatis.

Endpoint

MethodPathFungsi
POST/api/create-paymentBuat sesi pembayaran + QRIS dinamis
POST/api/check-paymentCek pembayaran masuk
GET/api/status/:sessionIdLihat status sesi
POST/api/gateway/createBuat sesi via API key (untuk integrasi eksternal)
GET/api/gateway/statusCek status via API key

Alur

  • Client kirim nama + nominal ke /api/create-payment.
  • Server bikin QRIS dinamis dari string QRIS statis merchant, plus pajak unik Rp 1-100 agar nominal gampang dicocokkan.
  • Client polling /api/check-payment tiap beberapa detik.
  • Server login ke GoBiz, tarik riwayat transaksi, cocokkan nominal, lalu tandai sesi sukses.
  • Notifikasi dikirim ke Discord webhook (opsional).

Deploy

  1. Import repo ini ke vercel.com/new.
  2. Isi environment variables (lihat .env.example).
  3. Deploy. Selesai.
